# 🎤 Presentación del Proyecto

Como parte del proyecto se ha desarrollado una presentación utilizando **Reveal.js**, con el objetivo de familiarizarse con herramientas modernas de presentación basadas en tecnologías web.

La presentación actúa como soporte visual para explicar:

* El problema de negocio planteado.
* La solución propuesta.
* La arquitectura del sistema.
* Las tecnologías utilizadas.
* Los principales retos encontrados.
* Los resultados obtenidos.
* Las lecciones aprendidas durante el desarrollo.

## Objetivos de aprendizaje

Además del desarrollo del scraper, esta práctica ha permitido trabajar competencias relacionadas con:

* Comunicación técnica.
* Presentación de proyectos tecnológicos.
* Organización de contenidos.
* Uso de Reveal.js como alternativa a PowerPoint.
* Elaboración de documentación técnica y funcional.

## Alcance

La presentación no pretende ser un producto final corporativo, sino una práctica complementaria orientada a reforzar las capacidades de exposición y comunicación de soluciones tecnológicas.

## Valor aportado

La combinación de:

* Código fuente
* Documentación técnica
* Control de versiones con Git y GitHub
* Presentación mediante Reveal.js

permite disponer de una visión completa del ciclo de desarrollo de un proyecto tecnológico, desde la identificación del problema hasta la comunicación de la solución desarrollada.
